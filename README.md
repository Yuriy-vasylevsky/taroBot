# 🌟 taroBot — Telegram Бот Таро з AI

**Професійний Telegram-бот для розкладів Таро з якісними AI-тлумаченнями українською мовою.**

---

## ✨ Основний функціонал

- Повна колода **78 карт** (пряме + перевернуте положення)
- Якісні **AI-тлумачення** через GPT-4o / 4o-mini
- 10+ популярних розкладів:
  - Карта дня
  - Запитай у Таро
  - Діалог з Таро
  - Так / Ні
  - Плюс / Мінус
  - Ти / Інший
  - Підкова
  - Любовний розклад
  - Енергетичний стан
  - та інші
- Банани 🍌 — основна валюта користувача
- Статистика активності та адмін-панель
- Повністю українською мовою
- Підтримка Webhook + Docker

---

## 🛠 Технології

- **Python 3.12**
- **aiogram 3.13+** (Webhook)
- **OpenAI GPT**
- **SQLite** + Persistent Volume (Railway)
- **Docker** (multi-stage)
- **Railway** (продакшен)
